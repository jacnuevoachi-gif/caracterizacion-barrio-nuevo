JAC NUEVO ACHI - VERSION FINAL RECOMENDADA

Esta carpeta usa EXACTAMENTE el archivo Excel que fue anexado en esta conversación.

IMPORTANTE SOBRE EL EXE:
Un .exe nativo de Windows debe compilarse en Windows. Este paquete contiene el constructor
para generar el ejecutable final de forma reproducible. No es correcto prometer un .exe
Windows universal generado desde un entorno Linux sin poder probarlo.

COMO GENERAR:
1. En un PC Windows instala Python 3.11 o superior.
2. Abre esta carpeta.
3. Haz doble clic en CONSTRUIR_EXE.bat.
4. Al finalizar estará:
   dist\JAC_Nuevo_Achi.exe

USO FINAL:
- Copia JAC_Nuevo_Achi.exe al PC de destino.
- Doble clic.
- El navegador se abre automáticamente.
- No se necesita Python en el PC de destino.
- No se necesita CMD.

DATOS:
El programa crea:
Documentos\JAC Nuevo Achi\datos\
Documentos\JAC Nuevo Achi\respaldos\

El archivo de trabajo es:
Formato_Caracterizacion_Barrio_Nuevo_Achi.xlsm

Cada guardado crea primero un respaldo.

NOTA:
"Ningún error en cualquier PC" no puede garantizarse porque Windows puede bloquear
programas descargados, faltar permisos, existir antivirus corporativo o diferencias
de arquitectura. El constructor está preparado para un Windows moderno de 64 bits.
